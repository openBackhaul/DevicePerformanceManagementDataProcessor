# p2CalculateEthernetKpis

Adds Ethernet KPIs to the historicalPerformanceData set. 

  
### Overview

This function processes a single PM data slice and adds:  
- transmitTraffic
- receiveTraffic
- frameLossInput
- frameLossOutput
