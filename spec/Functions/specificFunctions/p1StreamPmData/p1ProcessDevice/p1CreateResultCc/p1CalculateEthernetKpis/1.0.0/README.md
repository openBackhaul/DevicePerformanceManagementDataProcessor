# p1CalculateEthernetKpis

Adds Ethernet KPIs to the historicalPerformanceDataList. 

  
### Overview

This function processes each performance measurement data slice and adds:  
- transmitTraffic
- receiveTraffic
- frameLossInput
- frameLossOutput
